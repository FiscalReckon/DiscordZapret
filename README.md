## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
   * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — провайдер Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". Его отключение способно помешать настройке и работе Secure DNS на компьютере.

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/FiscalReckon/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите требуемый файл:
   * для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`;
   * для автоматического запуска выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты — ALT, FAKE и другие — пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc);</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб;
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert;
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После смены режима стратегию нужно перезапустить.  
  Значение в скобках показывает текущий статус: включено или выключено;
  - **`IPSet Filter`** — переключить режим обхода ресурсов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает.  
  В скобках отображается состояние:
    - `none` — IP-адреса не проверяются;
    - `loaded` — IP проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP;
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений;
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`;
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория;
  - **`Update Hosts File`** — обновить hosts <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord;</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений;
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы Discord;
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe (обход).  
Если этого не случилось, обратитесь к [#522](https://github.com/FiscalReckon/zapret-discord-youtube/issues/522).

### Не подошла ни одна стратегия

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора;
- добавьте скопированное в конец `hosts` либо замените ранее добавленный аналогичный фрагмент;
- сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Работа не гарантируется. Если этот способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FiscalReckon/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии со временем способны перестать работать.**
> Обнаружение определённой стратегии может произойти не сразу: какое-то время она работает, а затем перестаёт.
> В репозитории есть много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте отсутствие ошибок.
- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP.
- Попробуйте другие стратегии, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- См. [#765](https://github.com/FiscalReckon/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Откройте `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/FiscalReckon/zapret-discord-youtube/releases).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если соединения нет, закройте программу через значок замочка в панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив найденное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, переберите остальные стратегии.
- См. также [#251](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8F-использование) настроен.
- Желательно сначала определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузер тоже не подключается, повторно протестируйте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/FiscalReckon/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому исследовать и исправлять каждую отдельно невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что `ipset any` может нарушить открытие множества сайтов. Не оставляйте этот режим включённым постоянно: определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/FiscalReckon/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Сообщите о ней [здесь](https://github.com/FiscalReckon/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить список адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
